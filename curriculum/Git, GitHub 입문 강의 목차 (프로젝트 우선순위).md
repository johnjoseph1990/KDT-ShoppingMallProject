# Git, GitHub 입문 강의 목차 (프로젝트 우선순위)

> KDT-ShoppingMallProject의 실제 Git 사용 패턴(`master` 단일 브랜치, 다중 PC 작업,
> `git pull` → 수정 → `git push`, 충돌 시 직접 해결)을 기준으로 학습 우선순위를 매긴 표입니다.
> 강의 원본 목록은 아래 "전체 강의 목차"를 참고하세요.

---

## 우선순위 1 — 지금 당장 완벽히 알아야 함 (이미 매일 쓰는 것)

| 순번 | 강의이름 | 이유 |
| :--- | :--- | :--- |
| 02 | 버전 관리가 뭔가요? | 이후 모든 개념의 기초 |
| 04 | Git 초기화와 로컬 저장소 | 이미 clone된 저장소지만 원리 이해 필수 |
| 05 | 첫 번째 버전 만들기 | add/commit 흐름 |
| 06 | 만든 버전 GitHub에 올리기 | `git push origin master` 매번 사용 |
| 07 | 다른 사람이 만든 저장소 받아오기 | `git pull origin master` — 매 작업 시작 시 필수 (CLAUDE.md 규칙) |
| 08 | 가장 간단한 협업 시나리오 - 7가지 개념 리뷰 | pull→작업→push 전체 사이클 복습 |
| 10 | 그림으로 배우는 Git의 원리 | add/commit/push/pull이 내부적으로 뭘 하는지 — 개념이 헷갈릴 때 돌아올 곳 |

## 우선순위 2 — 이미 겪었거나 곧 겪을 문제 (다중 PC 작업 특성상 필수)

| 순번 | 강의이름 | 이유 |
| :--- | :--- | :--- |
| 12 | 브랜치(branch): 평행세계 나누기 | 지금은 master 하나만 쓰지만, 개념을 모르면 아래 컨플릭트 항목도 절반만 이해하게 됨 |
| 13 | 머지(merge): 두 버전 합치기 | pull = fetch + merge이므로 merge 원리를 모르면 pull도 반쪽 이해 |
| 14 | 컨플릭트(conflict) - 이론 | CLAUDE.md에 "충돌 발생 시 직접 해결 후 커밋" 규칙이 있음 — 언젠가 반드시 마주침 |
| 15 | 컨플릭트(conflict) - 실습 | 이론만으론 부족, 실제 손으로 한 번 해봐야 겁 안 남 |

## 우선순위 3 — 있으면 실수를 줄여주는 안전장치

| 순번 | 강의이름 | 이유 |
| :--- | :--- | :--- |
| 19 | 스태쉬(stash) | "커밋하긴 애매한데 pull은 해야 할 때" 자주 생기는 상황 (미완성 코드 두고 다른 PC로 이동 등) |
| 09 | 소스트리 GUI로 Git 다지기 | 초보자가 상태를 눈으로 보며 이해하기 좋음 (CLI 익숙해지면 안 써도 됨) |
| 11 | GUI로 add, commit, push, pull 하기 | 위와 세트 |

## 우선순위 4 — 당장 이 프로젝트엔 안 쓰지만 알아두면 좋음

| 순번 | 강의이름 | 이유 |
| :--- | :--- | :--- |
| 18 | 어멘드(amend) | "방금 커밋에 파일 하나 빠뜨렸다" — 가끔 쓸 일 있음. 단, CLAUDE.md에서 "amend 금지, 새 커밋으로" 원칙을 이미 정해뒀으니 참고용으로만 |
| 20 | 리셋(reset) | 되돌리기 개념은 알아야 하지만 `--hard`는 위험해서 실전에서 잘 안 씀 |
| 21 | 리버트(revert) | 이미 push된 커밋을 안전하게 되돌릴 때 — reset보다 실무에서 더 흔히 씀 |

## 우선순위 5 — 지금 프로젝트 구조상 거의 안 씀 (혼자/직접 push 방식이라)

| 순번 | 강의이름 | 이유 |
| :--- | :--- | :--- |
| 16 | 포크(fork): 저장소 통째로 복제하기 | 오픈소스 기여 등 "남의 저장소" 작업할 때 필요 — 이 프로젝트는 이미 write 권한 있는 팀 저장소 |
| 17 | 풀 리퀘스트(Pull request) | 지금은 master 직접 push 방식(CLAUDE.md 규칙). 나중에 팀 리뷰 프로세스 도입하면 그때 다시 볼 것 |
| 22 | 체리픽(cherry-pick) | 특정 커밋만 골라 옮기는 고급 기법 — 실무 빈도 낮음, 필요할 때 찾아봐도 충분 |
