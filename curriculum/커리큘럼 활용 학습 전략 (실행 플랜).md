## 진단: 왜 "정주행"이 아니라 이 전략인가

| 상황 | 판단 |
|------|------|
| 코드는 이미 있다 (AI 페어로 구현됨) | LEARNING_PLAN.md의 "Phase 0부터 재구축"은 지금 상황과 안 맞음 — **코드를 앵커로 삼는 역주행 학습**이 맞음 |
| 강의 925개 | 정주행하면 수백 시간 + 대부분 잊어버림 (수동 학습의 한계) |
| CONCEPT_INDEX.md 존재 | 개념→강의 역방향 사전이 이미 완성 — **찾아보는 용도**로 쓰면 됨 |
| docs/learning/ 노트 축적 중 | 작업할 때마다 개념 노트가 쌓이는 구조 — 여기에 강의를 연결하면 학습 루프 완성 |

핵심 원칙: **강의가 학습의 중심이 아니다. 코드가 중심이고, 강의는 코드를 설명해주는 해설지다.**

## 시스템: 3개의 루프

### 루프 A — 데일리: 작업 연동 학습 (매 개발 세션, +20분)

```
[작업 전 10분] 오늘 만들 기능 → CONCEPT_INDEX에서 개념 검색 → 해당 강의 1~2개만 시청 (예습)
      ↓
[작업 중] 핵심 로직 한 조각은 직접 작성 (Claude에게 "이 부분은 내가 짤게" — TODO(human) 방식)
      ↓
[작업 후 10분] docs/learning/ 노트에 두 가지 기록:
   ① 오늘 몰랐는데 알게 된 것 1줄
   ② 관련 강의 위치 (CONCEPT_INDEX에서 복사)
```

- 예습은 **최대 2개 강의**로 제한. 더 보고 싶어도 참는다 — 코드 없이 본 강의는 잊어버린다.
- Claude에게 세션 시작 시 요청: **"오늘 작업에 필요한 강의를 CONCEPT_INDEX에서 골라줘"**
- Claude에게 세션 종료 시 요청: **"오늘 나온 개념으로 퀴즈 3개 내줘"** (인출 연습 — 다시 읽기보다 기억에 3배 효과적)

### 루프 B — 위클리: 역주행 회독 (주 1회, 1~2시간)

이번 주에 **작성된 코드**를 기준으로 강의를 소급해서 본다.

```
1. git log --oneline --since="1 week ago" 로 이번 주 커밋 확인
2. 커밋에 등장한 개념의 강의를 CONCEPT_INDEX에서 찾아 몰아 보기 (3~5개)
3. 강의 하나 볼 때마다 "코드 재발견": 그 개념이 우리 코드 어디에 있는지
   파일:라인 을 직접 찾아서 docs/learning/ 노트에 추가
4. 마무리: 이번 주 노트 하나를 골라 자기 말로 3줄 요약 (파인만 기법 —
   설명이 안 되면 이해 못 한 것)
```

- 예: 이번 주 배송지 기능 → JPA 기본편 「단방향 연관관계」(24분) 시청 → `Address.java`의 `@ManyToOne` 라인을 직접 찾음 → "왜 LAZY가 아니지?" 같은 질문이 생기면 Claude에게 질문
- **2주 전 노트 다시 읽기**를 이 시간에 포함 (간격 반복 — 잊기 시작할 타이밍에 복습)

### 루프 C — 백본: 정주행 가치가 있는 유일한 두 강의 (매일 30분, ~10주)

모든 강의를 사전처럼 쓰되, 딱 **두 개만은 순서대로 완주**한다. 개념이 누적적이라 발췌가 안 되는 강의들이다:

| 순서 | 강의 | 분량 | 이유 |
|------|------|------|------|
| 1 | 스프링 핵심 원리 - 기본편 | 63강 (~11시간) | `@Service`, `@Autowired`, 생성자 주입이 "왜" 동작하는지. 이걸 모르면 스프링을 평생 외워서 씀 |
| 2 | 자바 ORM 표준 JPA - 기본편 | 53강 (~16시간) | 영속성 컨텍스트 → 변경 감지 → 연관관계 → 지연 로딩이 사슬처럼 연결됨. 중간부터 보면 이해 불가 |

- 하루 1~2강 (20~30분), 밥 먹듯이. 주말 몰아보기 금지 (분산 학습이 집중 학습보다 기억에 유리)
- 각 강의 시청 직후 **30초 셀프 퀴즈**: "이 개념이 우리 프로젝트 어디에 쓰였지?" 한 군데 말하기
  - 답이 안 나오면 CONCEPT_INDEX에서 확인하고 넘어감
  - 답이 없는 개념(예: 빈 스코프 프로토타입)이면 "우리는 안 씀, 왜냐면 ___" 형태로 답
- 완주 후 다음 백본: 자바스크립트 강의(66강) — React 코드를 문법째 외우지 않기 위해

### 진행 기록

```markdown
## 백본 진행 (루프 C)
- [ ] 스프링 핵심 원리 - 기본편 (0/63)
- [ ] 자바 ORM 표준 JPA - 기본편 (0/53)
- [ ] 자바스크립트 강의 (0/66)
```
→ 이 체크박스를 이 파일에서 직접 갱신한다. (강의 번호까지 기록하고 싶으면 옆에 `(~24강)` 식으로)

## 강의 녹화본 md 통합 (예정)

강의 녹화본을 전부 md 파일로 변환해 저장소에 넣는다. 이렇게 되면 Claude가 강의 내용을
직접 검색·인용할 수 있어서 세 루프가 전부 강화된다.

### 폴더 구조와 파일 규칙

```
curriculum/
├── lectures/
│   ├── 02-스프링핵심원리-기본편/
│   │   ├── 022-IoC-DI-그리고-컨테이너.md
│   │   └── 038-컴포넌트-스캔과-의존관계-자동-주입.md
│   ├── 09-JPA-기본편/
│   │   └── 006-영속성-컨텍스트-1.md
│   └── ...
```

- 폴더명: `{엑셀 시트 순번 2자리}-{강의명 축약}` — 우선순위 문서와 대응
- 파일명: `{강의순번 3자리}-{강의이름}.md` — 엑셀의 강의순번과 일치시켜 CONCEPT_INDEX에서 바로 찾을 수 있게
- 각 파일 상단에 메타 정보(frontmatter):

```markdown
---
course: 스프링 핵심 원리 - 기본편
no: 22
title: IoC, DI, 그리고 컨테이너
duration: 16분
---
```

### 녹화본이 들어오면 달라지는 것

| 루프 | 강화되는 점 |
|------|------------|
| 루프 A (데일리) | "오늘 작업 관련 강의 골라줘" → Claude가 녹취록 내용까지 검색해서 **정확히 필요한 부분만 발췌** 제시 |
| 루프 B (위클리) | 코드 재발견 시 강의 원문과 우리 코드를 나란히 비교 가능 |
| 루프 C (백본) | 시청 후 셀프 퀴즈를 Claude가 **실제 강의 내용 기반**으로 출제 — 강의에서 강조한 부분 위주로 |
| CONCEPT_INDEX | "강의 위치" 열이 텍스트 설명 → **클릭 가능한 파일 링크**로 업그레이드 가능 |

### ⚠️ 주의: 저작권

- 유료 강의 녹취록은 **개인 학습용**으로만. 현재 저장소는 비공개(PRIVATE)라 커밋 가능.
- **저장소를 공개로 전환할 일이 생기면, 그 전에 반드시 `curriculum/lectures/`를 이력에서 제거**해야 함 (공개 저장소에 올리면 강의 콘텐츠 재배포가 됨).

## 하지 말 것 (시간 낭비 순위)

1. **925개 정주행** — 수백 시간을 쓰고 90%를 잊는다. 백본 2개 외에는 전부 발췌.
2. **코드 없이 강의만 보는 날** — 강의는 반드시 그날 코드와 연결돼야 남는다.
3. **자바 기초 강의(98강)부터 시작** — 이미 실무 코드를 읽고 쓰는 중. 막히는 문법(스트림, 제네릭)만 사전 참조.
4. **여러 강의 동시 진행** — 백본은 한 번에 하나만.
5. **노트 없이 시청** — 본 강의는 반드시 docs/learning/ 어딘가에 흔적(1줄이라도)을 남긴다.

## Claude(멘토) 활용 규칙 — 학습 효과를 배로 만드는 요청들

| 타이밍 | 요청 문구 | 효과 |
|--------|-----------|------|
| 세션 시작 | "오늘 작업에 필요한 강의 CONCEPT_INDEX에서 골라줘" | 예습 대상 자동 선정 |
| 코드 작성 중 | "이 부분은 내가 직접 짤게, TODO로 남겨줘" | 능동 학습 (Learn by Doing) |
| 코드 이해 안 될 때 | "이 코드 흐름 설명해주고, 관련 강의 위치 알려줘" | 해설 + 강의 연결 |
| 세션 종료 | "오늘 나온 개념으로 퀴즈 3개 내줘" | 인출 연습 |
| 주말 (루프 B) | "이번 주 커밋 기준으로 볼 강의 골라줘" | 회독 대상 자동 선정 |
| 2주마다 | "docs/learning에서 2주 지난 노트 골라서 복습 퀴즈 내줘" | 간격 반복 |
