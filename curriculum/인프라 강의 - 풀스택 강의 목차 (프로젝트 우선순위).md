# 인프라 강의 - 풀스택 모든 강의 정리 (프로젝트 우선순위)

> 원본: `document/인프라 강의 - 풀스택 모든 강의 정리.xlsx` (13개 카테고리, 총 925개 강의)
> KDT-ShoppingMallProject의 실제 스택(Spring Boot 3.5, Java 17, Spring Data JPA, Spring Security,
> H2/PostgreSQL, React + Vite, TDD)을 기준으로 카테고리 단위 학습 우선순위를 매긴 문서입니다.
> Git/GitHub 강의 세부 우선순위는 [Git 강의 목차 (프로젝트 우선순위)](./Git,%20GitHub%20입문%20강의%20목차%20(프로젝트%20우선순위).md) 참고.

## 우선순위 1 — 지금 당장 필수 (매일 코드에 등장하는 개념)

| 카테고리 | 강의 수 | 이유 |
| :--- | :--- | :--- |
| 스프링 핵심 원리 - 기본편 | 63개 | IoC/DI, 컴포넌트 스캔, 빈 생명주기 — `@Service`, `@Repository`, `@Autowired`가 왜/어떻게 동작하는지의 기반. 이게 없으면 스프링 코드를 "외워서" 쓰게 됨 |
| 자바 ORM 표준 JPA - 기본편 | 53개 | 영속성 컨텍스트, 연관관계 매핑(`@ManyToOne` 등), 프록시/즉시·지연 로딩 — `Address.java`, `Order`, `Product` 엔티티 설계가 전부 이 원리 위에 있음 |
| 스프링 DB 2편 (JPA·스프링 데이터 JPA·트랜잭션 전파 파트) | 85개 | `findByMemberIdAndIsDefaultTrue` 같은 메서드 네이밍 규칙, `@Transactional` 전파 — `AddressService`의 "기본 배송지 교체" 로직과 직결 |
| GIT&GITHUB | 22개 | 이미 별도 문서로 우선순위 정리됨 — 매일 pull/push하는 도구이므로 여전히 1순위 |

| 카테고리 | 강의 수 | 이유 |
| :--- | :--- | :--- |

## 우선순위 3 — 백엔드 API 계층 상세 (인증/검증/예외 처리)

| 카테고리 | 강의 수 | 이유 |
| :--- | :--- | :--- |
| 스프링 MVC 2편 (검증, 로그인-쿠키/세션, 필터·인터셉터, 예외 처리 파트) | 127개 | `@Valid` 검증, `GlobalExceptionHandler`, 인증 처리 흐름 — Spring Security로 대체된 부분이 많지만 "왜 그렇게 설계됐는지" 원리는 동일 |
| 스프링 MVC 1편 | 69개 | 서블릿 → MVC 패턴 → 프론트 컨트롤러 직접 구현 — Controller가 내부적으로 어떤 문제를 해결하는 계층인지 이해 |
| 스프링 DB 1편 (JDBC, 트랜잭션 개념) | 55개 | JPA를 쓰기 전 "원래는 이렇게 SQL을 직접 다뤘다"는 배경 지식. JPA가 대신 해주는 일이 뭔지 감을 잡는 용도 |

## 우선순위 4 — 있으면 코드를 더 깊이 이해하게 해줌 (당장 급하지 않음)

| 카테고리 | 강의 수 | 이유 |
| :--- | :--- | :--- |
| 제대로 파는 자바 (Java) | 98개 | 기초 문법은 이미 실무 코드를 작성하는 수준이라 처음부터 볼 필요는 낮음. 스트림·제네릭·쓰레드처럼 막히는 부분만 사전처럼 찾아보면 충분 |
| 스프링 부트 - 핵심 원리와 활용 (자동 구성 파트만) | 104개 중 자동 구성 관련 ~16개 | `@SpringBootApplication` 하나로 모든 설정이 자동으로 되는 원리(`@Conditional`, 자동 구성) — 알면 좋지만 액츄에이터/모니터링(프로메테우스·그라파나) 부분은 지금 프로젝트 규모에 과함 |

## 우선순위 5 — 배포 단계에서 다시 꺼내 볼 것 (지금은 로컬 개발 단계)

| 카테고리 | 강의 수 | 이유 |
| :--- | :--- | :--- |
| 따라하며 배우는 도커와 CI환경 | 80개 | 지금은 `docker-compose up -d`로 로컬 PostgreSQL만 띄우는 수준. 이미지 빌드, 멀티 컨테이너 배포, Travis CI/GitHub Actions 심화는 실제 배포를 준비할 때 |

## 요약

- **지금 막힐 때마다 봐야 할 순서**: 스프링 핵심 원리 → JPA 기본편 → 스프링 데이터 JPA/트랜잭션 → (프론트 작업 시) 자바스크립트/HTML
- **"왜 이렇게 짜여있지?" 궁금할 때**: 스프링 MVC 1/2편, 스프링 DB 1편
- **지금 당장은 안 봐도 되는 것**: 자바 기초 전체 강의, 도커/AWS — 필요할 때 목차에서 찾아보는 용도로 남겨둠
