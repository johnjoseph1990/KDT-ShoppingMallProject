# Handoff: MINS Farmers Market (로컬푸드 쇼핑몰)

## Overview
대전·충남 지역 소농 직거래 쇼핑몰 프로토타입. Aesop 사이트를 벤치마킹한 미니멀·세리프 중심의 차분한 톤. 홈, 상품 목록, 상품 상세, 장바구니/체크아웃, 농부 이야기, 브랜드 소개 화면을 포함한 클릭 가능한 인터랙티브 프로토타입.

## About the Design Files
이 번들의 파일(`MINS Farmers Market.dc.html`)은 **디자인 레퍼런스로 만든 HTML 프로토타입**입니다. 실제 배포할 코드가 아니라 의도한 화면·동작을 보여주는 참고자료입니다. 목표 코드베이스(React/Vue/기타 기존 스택)의 기존 패턴과 라이브러리를 사용해 이 디자인을 재구현해야 하며, 아직 프레임워크가 없다면 프로젝트에 적합한 프레임워크를 선택해 구현하면 됩니다.

## Fidelity
**High-fidelity.** 색상, 타이포그래피, 간격, 인터랙션이 최종안에 가깝습니다. 코드베이스의 기존 라이브러리로 픽셀 단위로 재현하는 것을 목표로 합니다.

## Screens / Views

### 1. 홈 (Home)
- **목적**: 브랜드 소개 + 이번 주 수확물 진입점
- **레이아웃**: 상단 공지 배너(전체폭) → 스티키 헤더(72px) → 히어로(2단 그리드, 최소 88vh, 왼쪽 텍스트/오른쪽 영상 또는 이미지) → 이번 주 수확 4개 카드 그리드(4열) → 정기배송 배너(2단, 다크 배경 #333326) → 생산자 인용구 섹션
- **히어로 영상**: `<video autoplay loop muted playsinline>` — src는 prop `heroVideoSrc`로 주입, 없으면 poster 이미지로 폴백. 커스텀 컨트롤 바(재생/정지, 음소거, 진행바, 전체화면)를 영상 하단에 오버레이.

### 2. 쇼핑 (상품 목록)
- **레이아웃**: 카테고리 필터 버튼 행(전체/채소·과일/베이커리·간식/꾸러미·정기배송) → 3열 카드 그리드, 셀 간격 1px(구분선 효과, 배경 #DDDACA)
- **카드 구성**: 이미지(4:5 비율) → 상품명(세리프) → 한 줄 설명 → 가격 → "장바구니에 담기" 버튼

### 3. 상품 상세
- **레이아웃**: 2단(1.1fr/1fr), 왼쪽 스티키 이미지(뷰포트 높이), 오른쪽 스크롤 콘텐츠
- **콘텐츠**: 뒤로가기 링크 → 카테고리·원산지 → 상품명(세리프, 26-36px) → 설명 → 재배방식/수확시기/보관/생산자 4행 표 → 수량 스테퍼 + "장바구니에 담기"(가격 표시) → 하단 주의사항 텍스트

### 4. 농부 이야기 (목록)
- **레이아웃**: 인트로 섹션 → 농부별 2단 섹션(이미지 4:3 / 텍스트: 지역, 농가명·이름, 인용구(이탤릭 세리프), 짧은 스토리, "이야기 더 보기 →" 버튼)

### 5. 농부 이야기 (상세) — 신규
- **레이아웃**: 상품 상세와 동일한 2단 구조(왼쪽 스티키 이미지 / 오른쪽 스크롤). 뒤로가기 → 지역 → 농가명·이름(제목) → 인용구 → 짧은 스토리 + 상세 스토리(긴 본문) → "이 농가의 상품 보기" CTA
- **트리거**: 농부 이야기 목록의 "이야기 더 보기" 버튼 클릭 시 해당 농부 인덱스로 이동

### 6. 브랜드 소개
- **레이아웃**: 중앙 정렬 헤드라인 → 3열 통계 블록(50km/24시간/23농가) → 약속 본문 텍스트 + CTA

### 7. 장바구니 (드로어)
- **레이아웃**: 화면 우측 고정 패널(440px), 오버레이 배경. 상단 헤더+닫기, 스크롤 아이템 리스트(이미지+이름+수량 스테퍼+삭제), 하단 배송 안내 문구·소계·주문하기 버튼

### 8. 체크아웃
- **레이아웃**: 2단(1.2fr/1fr). 왼쪽 배송정보 폼(받는분/연락처/주소/메모), 오른쪽 주문내역+배송비+합계+결제 버튼(베이지 배경 #F6F4E6)

### 9. 주문 완료
- **레이아웃**: 중앙 정렬 완료 메시지 + 홈으로 돌아가기 링크

## Interactions & Behavior
- 헤더 네비게이션: 쇼핑/농부 이야기/브랜드/장바구니(카운트 배지) — 전부 클라이언트 라우팅(단일 페이지 내 `page` state 전환)
- 상품 카드/상세에서 "장바구니에 담기" → 하단 토스트("OO — 장바구니에 담았습니다") 2.2초 노출
- 장바구니 수량 +/− 버튼, 삭제 버튼 즉시 반영
- 무료배송 기준액(기본 40,000원) 미달 시 "OOO원 더 담으면 무료 배송" 안내, 충족 시 "무료 배송으로 보내드립니다"
- 카테고리 필터 버튼: 선택 시 배경 #333330/글자 #FFFEF2로 반전
- 모든 클릭 가능 요소에 hover 상태(배경/글자색 반전 또는 #75775E로 변경)
- 히어로 영상 컨트롤: 재생/정지 토글, 음소거 토글, 진행바(250ms 폴링으로 currentTime/duration 갱신), 전체화면 요청
- 페이지 전환 시 `fadeUp` 트랜지션(0.4-0.5s ease)과 스크롤 최상단 이동

## State Management
- `page`: 'home' | 'shop' | 'detail' | 'story' | 'farmerDetail' | 'about' | 'checkout' | 'done'
- `cat`: 현재 선택된 상품 카테고리 필터
- `selId`: 상세 페이지에서 보고 있는 상품 id
- `selFarmerIdx`: 농부 상세에서 보고 있는 농부 인덱스
- `qty`: 상세 페이지 수량 선택값
- `cart`: `[{id, qty}, ...]` 배열
- `cartOpen`: 장바구니 드로어 열림 여부
- `toast`: 현재 표시 중인 토스트 메시지(상품명)
- 영상 상태: `vPlaying`, `vMuted`, `vProgress`(0-100)

## Design Tokens

### Colors
- 배경(기본): `#FFFEF2`
- 텍스트(기본): `#333330`
- 텍스트(보조/설명): `#6D6C61`
- 강조/링크 hover: `#75775E`
- 다크 섹션 배경: `#333326` / `#3F3F30`
- 다크 섹션 텍스트: `#E5E3D3` / `#C9C7B2` / `#A9A98F`
- 구분선/보더: `#DDDACA`
- 카드/이미지 배경(플레이스홀더): `#EDEADB`
- 서브틀 hover 배경: `#F6F4E6`

### Typography
- 세리프(제목/헤드라인/인용구): `Noto Serif KR`, weight 200-500
- 산세리프(본문/UI): `Noto Sans KR`, weight 300-500
- 헤드라인: `clamp(24px, 2.4-3.8vw, 50px)`, line-height 1.4-1.6, letter-spacing -0.01em
- 라벨(카테고리 태그): 12-13px, letter-spacing 0.14em, `#75775E`
- 본문: 14-15px, line-height 1.8-2.1, weight 300

### Spacing / Layout
- 헤더 높이: 72px
- 섹션 패딩: `clamp(20px, 5vw, 72px)` 좌우, `clamp(32-56px, 6-9vw, 88-120px)` 상하
- 그리드 갭(카드): 1px (구분선 효과, 배경색으로 표현)
- 보더: 1px solid `#DDDACA`

### Border radius / Shadow
- 전체적으로 `border-radius: 0` (직각 미학) — 원형은 아이콘 버튼(재생/음소거/전체화면)에만 사용
- 그림자 없음 — 보더와 배경 대비로만 구분
